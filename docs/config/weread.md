# 微信读书

微信读书模块用于展示书架与阅读记录，主题提供 `weread.html` 自定义页面模板，
数据由[微信读书插件](https://github.com/yeora26/halo-weread-plugin)提供，访客无需登录即可查看。

::: info
该页面依赖 Halo **2.27+** 的能力；主题声明的兼容范围为 `>=2.27.0`。
:::

## 配置项一览

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `weread_page_title` | 文本 | — | 页面标题（顶部标题与浏览器标签页标题）；插件自带的标题区会自动隐藏以避免重复 |
| `weread_page_subtitle` | 文本 | — | 页面副标题 |

留空时由模板回退到默认文案，不会导致页面报错。

## 使用方式

1. 安装并启用微信读书插件
2. Halo 后台 → **页面** → **新建** → 自定义模板选择「**微信读书**」（`WeRead`）
3. 发布页面并加入导航菜单

页面地址由创建页面时设定的 slug 决定，主题不提供固定路由。
