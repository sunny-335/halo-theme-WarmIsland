# 订阅页面

订阅页面按时间倒序展示博友们的最新文章，即原先「朋友圈 / feed 聚合」所提供的能力。
现在它由 **Halo 官方「链接管理」（PluginLinks）插件的 RSS 订阅**驱动，主题提供
`page_subscriptions.html` 自定义模板负责前端展示。

## 使用方式

1. 安装并启用 [链接管理插件](https://www.halo.run/store/apps/app-hfbQg)，在插件中维护博友链接的 RSS 订阅源
2. 进入 Halo 后台 → **页面** → **新建**
3. 选择自定义模板「**订阅**」（`Subscriptions`，对应 `page_subscriptions.html`）
4. 发布页面，并按需加入导航菜单

> 页面地址由你创建页面时设定的 slug 决定，主题**不提供固定的 `/subscriptions` 路由**；
> 只有插件提供的扩展页面（如 `/links`、`/moments`）才是固定路由。

## 页面内容

每条订阅动态是一张卡片，包含：

- 作者头像（缺失时显示首字占位）、作者名称与主页链接
- 发布日期
- 文章标题（点击跳转原文）、摘要
- 空数据时的友好提示，以及未安装链接管理插件时的安装引导

标题与作者链接均使用 `target="_blank"` + `rel="noopener noreferrer"`，
主题本身不会向第三方发起请求。

## 展示与加载

在[订阅配置](/config/subscriptions)中可调：

| 能力 | 可选值 |
| --- | --- |
| 布局 | 单列列表卡片 / 网格卡片（窄屏自动收敛列数） |
| 加载方式 | 底部分页（较新 / 较旧）/ 下滑自动加载 |
| 每页条数 | 1–100，默认 20 |
| 标题与副标题 | 自定义文本 |

## 从「朋友圈」迁移

`plugin-friends`（朋友圈）插件已不再提供，原来的 `/friends` 页面与「朋友圈」设置分组
仅作为旧站点兼容保留，模板检测到插件不可用时会显示空状态。迁移步骤：

1. 安装 / 启用「链接管理」插件，把原本在朋友圈插件里维护的 RSS 订阅源迁到链接管理插件的订阅中
2. 新建一个页面并选择「订阅」自定义模板
3. 确认动态正常展示后，删除旧的 `/friends` 页面与菜单项
