# 自定义页面

自定义页面是 Halo 的独立页面功能，用于创建关于、留言板、订阅动态、微信读书等独立内容页面。

## 使用方式

1. 进入 Halo 后台 → **页面** → **新建**
2. 填写页面标题和内容
3. 可选：在「自定义模板」中选择主题提供的模板
4. 发布页面，并把页面加入导航菜单

页面地址由创建时设定的 slug 决定，主题不为自定义模板提供固定路由。

## 页面模板

`theme.yaml` 中注册了 3 个自定义模板，加上默认的 `page.html` 共 4 种：

| 模板 | 模板文件 | 说明 |
|------|---------|------|
| 默认 | `page.html` | 标准内容页面 |
| 留言板（MessageBoard） | `page_messageboard.html` | 带评论的留言墙，标题与副标题可配置 |
| 订阅（Subscriptions） | `page_subscriptions.html` | 博友文章订阅动态，依赖官方「链接管理」插件的 RSS 订阅 |
| 微信读书（WeRead） | `weread.html` | 微信读书书架，依赖微信读书插件，访客免登录查看 |

### 留言板模板

选择留言板模板后，页面会集成评论组件，访客可以直接留言。标题和副标题在
**主题设置 → 留言板** 中配置，详见[留言板配置](/config/messageboard)。

### 订阅模板

feed / RSS 聚合不再依赖已停止提供的「朋友圈」插件，而由官方
「链接管理」（PluginLinks）插件的订阅能力提供。使用步骤：

1. 安装并启用[链接管理插件](https://www.halo.run/store/apps/app-hfbQg)，维护博友链接的 RSS 订阅源
2. 新建页面，自定义模板选择「订阅」
3. 在**主题设置 → 订阅**中调整每页条数、加载方式与布局，详见[订阅配置](/config/subscriptions)

未安装插件或暂无订阅动态时页面会显示友好提示，不会报错。
完整说明见[订阅页面](/pages/subscriptions)。

### 微信读书模板

选择「微信读书」模板后展示书架与阅读记录，标题 / 副标题在
**主题设置 → 微信读书** 中配置，详见[微信读书配置](/config/weread)。
该页面依赖 Halo 2.27+ 的能力。

## 页面功能

自定义页面支持：

- 富文本编辑器内容
- 封面图
- 评论组件
- 自定义模板选择
